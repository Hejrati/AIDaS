This prerelease brings faster tutorial and desktop interactions, guided annotation, optimized deeper-layer processing, flexible Excel compilation, and diagnostic feedback reports.

### General

- Open the tutorial and switch between Prepare, Run & review, Save & continue, and Details with less layout and drawing work.
- Improve responsiveness when resizing windows, switching tabs, browsing image results, selecting batch rows, and completing folder paths.
- Open **Send feedback** from the header or Help menu in either interface mode. Review diagnostics, save a ZIP with optional logs and selected attachments, and open an email draft for manual submission.

### Step 2 — Annotation

- Guide batch fovea placement and nasal/temporal selection with numbered prompts and temporary visual cues.
- Keep annotation labels readable during zooming and panning, with scaling and overlap avoidance that leave trace coordinates unchanged.

### Step 3 — Flatten Retina

- Select **Optimized deeper layers** to process the retained deeper retinal boundaries while skipping superficial-layer calculations. Select the matching main and output scripts together.
- Prepare R in the background with faster package checks and responsive cancellation.
- Generate previews faster and reduce unnecessary intermediate output files.
- Follow live elapsed time in the bottom status bar and retain the final processing duration.

### Step 4 — ROI Analysis

- Prepare automatic ROI detection across batch files in the background and cache loaded images for faster tab switching.
- Build stacks for all ready tabs with one action and see how many tabs are ready to build.
- Use **Go to Step 5** to transfer the complete measurement batch and start Excel compilation automatically.

### Step 5 — Excel Compilation

- Discover nasal and temporal Excel results recursively, including nested export folders, across custom group names or LE/RE groups.
- Preserve complete subject IDs, including leading zeros and suffixes, and include subjects with results from only one side.
- Combine rrMCP/AR, ELM-RPE, and ONL measurements, retain optional fovea extraction, and record source paths and extraction status in the workbook.
- Explore measurement folders in an expandable tree with file-type icons, Excel filtering, Refresh, Expand all, and Collapse all. Background scanning and visible-row rendering keep large inventories responsive.
