Fixes the Step 4 loading freeze before the first plots appear.

### Responsive Step 4 file preparation

- Read the first OCT file and load the plotting libraries in a background worker so the loading progress bar keeps animating.
- Keep all Tk widget and Matplotlib figure creation on the UI thread.
- Paint the initial plot after its canvas layout settles, avoiding a redundant render at the provisional size.
- Reuse the prepared volume when activating the first tab instead of reading the file twice. Other tabs retain their existing on-demand loading and caching behavior.
- Cancel obsolete loading callbacks when a run is replaced or closed. A late result from an older read cannot overwrite the newly selected files.
- Release the loading indicator and modal grab after success, cancellation, and file-read errors.

### Profiling and validation

The local synthetic-file benchmark improved first-file/plot preparation from **1.71 to 0.82 seconds**, and reduced the longest UI heartbeat pause from **1.55 to 0.14 seconds**. Timings depend on hardware and files.

Added `release_tools/profile_step4_loading.py` and regression coverage for a deliberately blocked read, live progress animation, cancelled results, replacement loads, and error cleanup. The full suite ran **1,022 tests with no failures and four R-dependent tests skipped locally**. The Windows release workflow performs its checks before publishing the installer and SHA-256 checksum.

Includes the fixes from the earlier 3.4.2 alpha releases. The UI layout, ROI calculations, and plot behavior are preserved.
