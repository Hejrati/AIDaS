v3.4.5a2: Check for updates on every app launch

- Automatically check for newer releases every time AIDaS opens in either Modern or Classic mode, including when older preferences disabled update checks.
- Prompt when an update is available and offer declined updates again on the next launch.
- Keep failed automatic checks quiet so users can continue working without a popup. Manual checks remain available through Help > Check for Updates.
- Remove the update-check opt-out from Settings and explain the automatic launch behavior.
- Skip checksum lookups for current and older releases to avoid delaying update prompts.
