This prerelease keeps folder selection and processing responsive across the workflow and makes the feedback form easier to use.

### Steps 1–4 — Folder scanning and processing

- Limit batch folder scans to 500 unique subfolders, prevent linked-folder cycles, and show an inline message asking for a smaller selection when the limit is exceeded.
- Cancel obsolete scans and ignore their results when another folder is selected or a processing window is closed.
- Restore controls when a worker cannot start or exits without returning a result, while allowing active processing to continue normally.
- Keep progress updates responsive during segmentation, flattening, ROI loading, and stack creation, and stop completion polling when work ends or a window closes.
- Recover from stalled AI communication and clean up cancelled subprocesses without waiting indefinitely for inherited output pipes.

### Step 5 — Excel compilation

- Reject selections containing more than 500 nested subfolders before compilation and show the explanation in the folder preview without a popup.
- Disable Excel creation until a valid folder scan completes, reject partial scan results, and restore compilation after a valid folder is selected.
- Recheck the folder limit before compiling so a growing directory cannot bypass the selection limit or replace an existing workbook with partial results.

### General — Feedback and folder suggestions

- Scroll the feedback form from anywhere in the window, including over text boxes, with smoother batched scrolling.
- Open diagnostics through the clickable “review before sharing” text and mark required fields with red asterisks.
- Reuse the diagnostics preview window and load large reports incrementally for faster review.
- Stop folder suggestions from remaining pending when a lookup worker fails or finishes without a result.
