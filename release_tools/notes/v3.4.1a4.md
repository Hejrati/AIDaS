This alpha release improves responsiveness across image loading, segmentation review, analysis tabs, and Settings while preserving the existing layout and analysis results.

### Faster image browsing and editing

- Scan the Step 1 SDB work queue in the background, cancel obsolete scans, and update folder lists without repeatedly rebuilding them.
- Speed up SDB previews with equivalent NumPy peak detection and exact intensity histograms.
- Reuse unchanged Step 2 canvas images and dense boundary overlays when switching segmented-image tabs. Changed vertices, editing handles, zoom, and viewport sizes still trigger the required redraws.
- Cache unchanged layer lines when `<` or `<<` moves them to Incomplete. Restore them immediately with `>` or `>>` without rerunning AI segmentation. Edited or manually redrawn lines invalidate their cached copies; fresh inference updates only the requested missing layers. Caches remain isolated to each image tab.
- Disable **Go to Step 3** immediately whenever any open result tab has a missing layer boundary. The handoff also checks all six boundaries in every tab before saving or advancing.

### Faster Step 4 analysis and tab switching

- Compute intensity profiles from the ROI region and reuse them during automatic ROI detection and measurement.
- Warm up detection tools in the background and remove the transient busy popup for automatic ROI detection. Progress and error feedback remain available.
- Reuse ROI grid cells, curves, labels, and profile plot artists instead of recreating them on every selection.
- Cache unchanged measurement values and update only changed result-table rows.
- Use partial redraws for grid hover feedback, including narrow and high-DPI layouts, and prevent hidden canvases from resizing the active plot.

### More responsive Settings

- Paint rounded controls after the dialog reaches its final layout.
- Combine bursts of mouse-wheel input into one viewport move while preserving scrolling distance and limits.
- Cancel queued scroll work and remove local bindings when the window closes.

### Validation and profiling

Added repeatable synthetic-data profiling tools and regression coverage for canvas edits, cache invalidation, tab isolation, rendering, scroll behavior, and Step 3 handoff requirements. Representative local measurements:

| Operation | Before | After |
| --- | ---: | ---: |
| First SDB preview | 1.69 s | 0.23 s |
| Automatic computation for 20 ROIs, warmed up | 0.258 s | 0.033 s |
| Step 4: 12 switches across four populated tabs | 8.29 s | 0.63 s |
| Step 2: 12 switches across four dense segmented tabs | 3.59 s | 2.49 s |
| Settings opening | 0.50 s | 0.38 s |
| Settings: 100 wheel events in bursts | 0.17 s | 0.11 s |

Timings are workload- and machine-dependent. Local validation excludes four R integration tests that require the CI R environment; the release workflow runs its Windows tests and installer checks before publishing the installer and SHA-256 checksum.
