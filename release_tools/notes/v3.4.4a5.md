This prerelease automates Excel creation, simplifies Step 3 outputs, and improves update checks and measurement folder handling.

### General

- Check for new updates whenever AIDaS opens, while respecting the update preference in Settings.

### Step 3 — Flatten Retina

- Generate LIGHT exports and previews across all bundled R script variants without creating DARK-named output files.
- Save cleaned thickness measurements directly as `_thickness_vs_distance_from_fovea_LIGHT.txt`, without a separate LIGHT2 copy.
- Preserve the established LIGHT measurements and continue reading older saved workspaces and measurement folders.

### Step 4 — ROI Analysis

- Start Excel creation automatically once all stacks in the current run have finished saving.

### Step 5 — Excel Compilation

- Queue distinct folders received from Step 4 so each can finish compiling, and prevent duplicate requests from starting overlapping work.
- Show the saved workbook path in the app without an additional confirmation popup.
- Prefer current LIGHT thickness files over older LIGHT2 copies while retaining support for legacy inputs.
- Handle repeated folders and cyclic directory links during measurement discovery without excluding deeply nested results.
- Limit repeated automatic creation requests to five attempts per processing run and keep manual creation available.
- Stop background event polling when compilation is idle and restore controls when a worker fails or ends unexpectedly.
