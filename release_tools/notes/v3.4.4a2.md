This prerelease adds flexible Excel compilation, an interactive measurement folder explorer, and diagnostic feedback reports, with faster tutorial navigation and desktop interactions.

### Excel compilation and workflow handoff

- Discover nasal and temporal Excel results recursively, including nested export folders, and combine results across custom group names or LE/RE groups.
- Preserve complete subject IDs, including leading zeros and suffixes, and include subjects with results from only one side.
- Combine rrMCP/AR, ELM-RPE, and ONL measurements, retain optional fovea extraction, and record source paths and extraction status in the workbook.
- Use **Go to Step 5** to transfer the complete Step 4 batch root and start compilation automatically, while preserving a chosen output destination and fovea option.

### Measurement folder explorer

- Explore the selected Step 5 input directory in an expandable tree with icons and descriptions for Excel workbooks, thickness tables, fovea measurements, flattened images, and image stacks.
- Filter to Excel results, refresh directory contents, and expand or collapse folders without leaving the workspace.
- Scan folders in the background and draw visible rows to keep large inventories responsive.

### Feedback and diagnostic reports

- Open **Send feedback** from the header or Help menu in either interface mode.
- Review app, system, processing, and recent error information, then save a diagnostic ZIP with optional logs and selected attachments.
- Open a prepared email draft and attach the saved report for manual submission.

### Tutorial and desktop responsiveness

- Open the tutorial and switch between Prepare, Run & review, Save & continue, and Details with less layout and drawing work.
- Improve responsiveness when resizing windows, switching tabs, browsing image results, selecting batch rows, and completing folder paths.
- Show Step 3 elapsed time in the shared workflow status bar.
