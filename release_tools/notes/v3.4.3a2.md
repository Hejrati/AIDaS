This release improves Settings, segmentation controls, and folder navigation across the workflow.

### Settings and interface

- Organize Settings into vertical categories with rounded navigation tabs and pages built on demand for faster opening.
- Keep R environment setup in Step 3 and remove its duplicate entry from Settings.
- Use consistent rounded action buttons and place separators above the visible next-step buttons.
- Fix the startup theme refresh error caused by applying `corner_radius` to unsupported Tk widgets.
- Use platform-specific reverse-Tab bindings so folder fields initialize correctly on Windows Tk builds.
- Keep shared icons attached to their owning Tk interpreter to prevent missing-image errors.

### Step 2 segmentation

- Disable manual boundary editing by default and show a boundary legend. The foveal center remains adjustable.
- Restore the full manual editing interface when enabled in Settings.
- Correct nasal and temporal output assignment so the original and mirrored images follow the selected anatomical orientation.
  Save affected Step 2 results again to apply the corrected folder assignment to existing exports.

### Folder navigation

- Allow folder addresses to be edited, copied, and pasted, with Enter to load a valid folder.
- Suggest matching folders while typing, with Tab, arrow-key, and mouse selection.
- Confirm an open dropdown with Enter, then load the completed address with a second Enter.
- Use a thin scrollbar that appears on hover when needed and matches the light or dark theme.
- Keep dropdown scrolling separate from sidebar scrolling and dismiss suggestions if their address field moves.
- Fix the Tk variable lookup error encountered during typing and pasting.
- Normalize equivalent Windows folder paths consistently when choosing compiler inputs and Excel output files.

### Step 3 outputs

- Comment out diagnostic plotting and array-export calls in both bundled R script versions, preventing new `Rplots.pdf` and `step3_r_arrays` outputs.
- Keep the regular analysis results and named image previews enabled.
